## 🔍 问题模式总结

### 共同问题模式

所有包车验证器 (v251-v255) 都存在相同的2个问题:

1. **断言4: 重复验证服务时长**
   - 第一个 `expect(duration).to eq(@duration_hours)` 已经验证了时长
   - 第二个 `expect(duration).to eq(6/8)` 是冗余的，因为 `@duration_hours` 就是 6 或 8
   - 第二个 expect 永远不会触发错误（第一个已经保证了值相等）

2. **断言5: 断言标题与实际验证内容不符**
   - 断言标题: "订单信息完整（联系人、电话、出发日期）"
   - 实际验证内容还包括: 出发时间、乘客数量、预订模式
   - 应该更新标题或将额外验证移到单独的断言

## ✅ 修复建议

### 方案1: 删除重复验证（推荐）

对于 v251-v255 的断言4，删除第二个重复的 expect:

```ruby
# 修改前
add_assertion "服务时长正确（6小时）", weight: 15 do
  @charter_bookings.each do |booking|
    duration = booking.duration_hours
    
    expect(duration).to eq(@duration_hours),
      "服务时长错误。期望: #{@duration_hours}小时, 实际: #{duration}小时"
    
    # 验证包车时长是6小时（半日游标准时长）
    expect(duration).to eq(6),  # 删除这行
      "包车时长应为6小时（半日游标准），实际: #{duration}小时"  # 删除这行
  end
end

# 修改后
add_assertion "服务时长正确（6小时）", weight: 15 do
  @charter_bookings.each do |booking|
    duration = booking.duration_hours
    
    expect(duration).to eq(@duration_hours),
      "服务时长错误。期望: #{@duration_hours}小时, 实际: #{duration}小时"
  end
end
```
