**验证题目分类：**

#### 基础预订类（V001-V050）
- 航班预订、酒店预订、火车票预订、景点门票等单一业务验证
- 示例：V010 "查询并预订上海到北京最便宜的航班"

#### 组合预订类（V051-V100）
- 机票+酒店、火车+门票等组合业务验证
- 示例：V055 "预订往返机票+3晚酒店套餐"

#### 优惠策略类（V101-V150）
- 会员折扣、优惠券使用、促销活动等验证
- 示例：V120 "使用满减券预订酒店套餐"

#### 特殊场景类（V151-V200）
- 退改签、多乘客、儿童票、保险加购等验证
- 示例：V175 "预订3大1小家庭出游套餐含保险"

#### 高级功能类（V201-V250）
- 定制游、包车、签证、出境服务等复杂验证
- 示例：V210 "定制5天云南深度游+导游服务"

#### 综合场景类（V251-V320）
- 多业务组合、跨场景操作的综合验证
- 示例：V301 "规划并预订完整三亚5日游（机票+酒店+门票+租车）"

**Verifier系统功能：**

1. **自动化验证引擎**
   - 任务模拟执行（simulate方法）
   - 数据准备与查询（prepare方法）
   - 结果验证与评分（verify方法）
   - 加权断言评分机制（0-100分）

2. **数据隔离机制**
   - 基于data_version的会话隔离
   - 独立数据包加载（app/validators/support/data_packs/v1/）
   - 自动数据清理与重置

3. **执行管理**
   - Web API接口（GET /api/tasks、POST /api/tasks/:id/start、POST /api/verify/run）
   - 批量验证执行（rake validator:simulate）
   - 单题验证执行（rake validator:simulate_single[validator_id]）
   - 执行结果记录（ValidatorExecution模型）

4. **质量保证工具**
   - 静态代码检查（rake validator:lint）
   - 数据包验证（rake validator:validate_data_packs）
   - 验证器ID格式检查（自动化）
   - ERB HTML结构验证（bin/validate_erb_html）

5. **数据包管理**
   - 12个业务模块数据包（flights.rb, hotels.rb, trains.rb等）
   - 基础数据包（base.rb - 城市、目的地、用户）
   - 一键重置基线（rake validator:reset_baseline）
   - 时区感知日期生成（Date.today基准）

## 四、技术栈清单

### 后端技术
- **框架** - Ruby on Rails 7.2
- **数据库** - PostgreSQL 14（含RLS多租户隔离）
- **配置管理** - Figaro（环境变量管理）
- **后台任务** - Solid Queue（无需Redis）
- **分页** - Kaminari
- **服务器** - Puma
- **测试框架** - RSpec
- **友好URL** - FriendlyId

### 前端技术
- **CSS框架** - TailwindCSS v3
- **JavaScript** - Stimulus + Turbo（Stream响应）
- **实时通信** - ActionCable（WebSocket）
- **文件存储** - Active Storage（本地磁盘）
- **PWA** - Service Worker + Manifest
- **支付系统** - 自研支付确认弹窗系统
  - 模拟指纹验证界面（点击切换密码支付）
  - 6位数字密码输入键盘
  - 支付密码后端验证（`/profile/verify_pay_password`）
  - 支付状态动画展示（正在付款 → 付款成功）
  - 用户余额/里程扣款逻辑
  - 支持余额+里程混合支付（会员商城）

### 移动应用
- **封装技术** - Trusted Web Activity (TWA)
- **构建工具** - Gradle 7.4
- **目标平台** - Android SDK 34
- **签名机制** - Android Keystore

### DevOps
- **容器化** - Docker + Docker Compose
- **Web服务器** - Nginx（反向代理）
- **进程管理** - Foreman（开发环境）
- **部署脚本** - deploy.sh（一键部署）
